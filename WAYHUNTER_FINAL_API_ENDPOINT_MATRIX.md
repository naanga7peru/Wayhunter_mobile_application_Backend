## Endpoint completeness limitations

- No M4 endpoints are discovered. M5 draft CRUD is mapped only under the explicit Development feature gate described above; this does not establish production readiness.
- The matrix lists routes discoverable from current controller attributes and known route constants. It does not include framework-generated OpenAPI routes or SignalR negotiate internals as controller actions, and does not prove deployed routing or client compatibility.
- “Implemented” never means fully accepted. Persistence mode, authorization source, schema, provider and tests are shown separately to prevent source presence from being misread as production readiness.
- M5's four development-only draft endpoints are the only newly mapped HTTP surface in the current uncommitted completion work.
