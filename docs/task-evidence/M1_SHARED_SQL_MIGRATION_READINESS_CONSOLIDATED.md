## 6. Rollback and Recovery

Shared migration policy: coordinated and forward-only.

Before migration:
- Capture database backup and recovery point
- Verify restore permissions and procedure
- Capture existing migration IDs and schema
- Review compatibility of existing data
- Establish a maintenance and failure response plan

On failure:
- Stop the rollout
- Preserve logs and failed SQL evidence
- Assess whether a safe corrective forward
  migration is possible
- Otherwise follow the approved restore process
- Reconcile application/database version compatibility
- Re-run integrity and regression verification

Do not automatically reverse destructive SQL changes
or assume EF Down() restores deleted data.
