## Proposed HTTP contract

Paths are relative to the prefixes shown. M is /api/mobile/v1/hunter, A is /api/admin/v1/hunter. Approve prefixes with API and client owners. Owner routes use M1 bearer and server-derived canonical user ID. Admin routes use M1 bearer plus an explicit ADM-04 permission. Discovery and leaderboard require confirmed visibility policy. Errors use the existing API error envelope. Common outcomes are 400 for invalid input, 401 for invalid session, 403 for denied Admin permission, 404 for missing or foreign owner resource, 409 for an invalid transition or conflicting retry, and 503 for unavailable required providers. See row-specific overrides.
